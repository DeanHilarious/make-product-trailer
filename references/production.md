# 宣传片制作参考

## 开工前

从对话和工作区找齐产品名、目标观众、实际能演示的功能、发布渠道、已有素材与品牌入口。有一个可验证的主线就可以开工。需要复用的真实产品画面优先选干净的当前录屏。缺少完整素材时，可以用同次录制中产品已加载的截图做结果定格。保留有辨识度的真实界面，避免让生成模型写 UI 文案、按钮、品牌或操作结果。

一个约 36 秒的参考节奏为 5 秒人物开场、5 秒产品入口、5 秒使用情境、7 秒关键操作、8 秒成果、6 秒片尾。按故事需要调整。每个镜头写下画面、动作、素材来源和通过标准，另记一行旁白与字幕。官网或商店状态需要核对当前来源。

## 火山方舟人物素材与旁白

- 先用当前产品的素材和生成服务约定。若选择火山方舟，检查 `arkcli auth status` 与 `arkcli resources list --modality video`。根据登录配置和模型支持能力选用可调用资源。套餐列表为空时，检查已有平台 Profile、已启用的模型和适用计费。平台模式若要求 Endpoint ID，使用已有接入点，或在模型服务已开通、明确允许的调用方式下用官方 API 的模型 ID。可选按量路由时核实使用范围和成本。开通、充值或创建新计费资源需要相应授权。[火山方舟视频生成 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)
- 按最终版幅比给出镜头构图。横竖共用素材时，优先让脸、双手与道具有竖向裁剪余量。单镜头写清人物外观、服装、道具、光线、机位、一个动作的起止与屏幕朝向。人物连戏尽量复用获准且受模型支持的参考素材，其余镜头沿用服装和道具，必要时用侧面、背影或手部特写。拟真人镜头按情景演绎呈现，不借用未经授权的真人形象或声音。
- 从关键一镜、小规模试样开始。旁白由独立音轨承担时，按模型支持关闭生成音频。用 `arkcli +gen --help` 核对当前参数，再调用 `arkcli +gen --modality video --model <可调用资源> --no-open --save-to <镜头目录> ...`，保存任务 ID。已拿到 ID 而等待超时时用 `arkcli gen get <任务ID>` 查询同一个任务。只在终态失败且原因可修复时提交替代任务。下载后抽查人脸、手、设备、衣着与影调，再决定其他镜头。
- 旁白可用 `arkcli +gen --modality audio --no-open --save-to <旁白目录> ...`，需要时用支持的字级时间戳。根据实际音频分句对齐字幕，检查品牌名、混合语言和停顿。旁白和配乐先在本地混成一条音轨，确认语音没有被截断。供应方密钥留在现有凭据管理中。生成用量、估价与实际账单分别记录。

## 产品录屏

- 先复现正常用户路径，使用公开或隔离的演示账号与虚构项目。录前清点账号、设备名、项目路径、消息、通知和网络地址，避免在成片暴露隐私。克服测试环境弹窗或授权门槛时，仅更改专用录制环境。产品真实页面用演示数据时如实标记。
- 开始操作前保留一个稳态，录到点击、加载、成功和可读成果。自动化只断言容器存在容易漏掉白屏和错误页，应读取结果的特定文本或状态。浏览器或模拟器录屏看不见合成层时，核对同次截图，通过短切到实际加载成功的定格弥补。
- 放大后重查所有可见提示、错误、地址和临时账号。可以截取相关 UI 模块，切到下一段干净的实录。避免更改产品文本伪装真实运行状态。

## 剪辑与验收

- 横版与竖版分别设置取景。横版可并列文案和手机，竖版把关键界面放大并靠上，人物镜头裁切后检查手机、手与脸。字幕通常一至两行，用有效的对比度，在频道预览中检查平台遮挡，按可访问的验证结果描述适配程度。
- [时间线模板](../assets/timeline.example.json) 按目标画布保存一份。各 `file`、`audio` 和 `captions` 路径相对于 JSON。 `seconds` 是成片时长，`start` 与 `speed` 是素材起点和速度。 `fit: "cover"` 填满镜头框，配合 `focus: [0.0..1.0, 0.0..1.0]` 调整宽高两个裁切方向。 `fit: "contain"` 保留完整素材，`inset` 指定镜头框距画布四边的偶数像素，顺序为左、上、右、下。画布尺寸使用偶数，PNG、JPEG、WebP 可直接做定格或片尾卡。脚本把各镜头源声音静音，使用显式提供的混音。移动字幕位置可用 `caption_bottom` 调整画布底部留白比例。
- [合成脚本](../scripts/compose.py) 使用 Python 标准库和 FFmpeg。硬字幕需要支持 `subtitles` 滤镜的 FFmpeg 与能显示所需字符的字体，使用 `caption_font` 指定。官网播放器可用 `caption_mode: "track"` 生成 MP4 软字幕，另从 SRT 输出 WebVTT。脚本做顺序剪辑、定格、画幅适配和验收解码。需要转场、动效、对白混音时用项目剪辑工具或提前生成相应素材。

  ```sh
  python3 <技能目录>/scripts/compose.py timeline.json trailer.mp4 --ffmpeg <FFmpeg可执行文件>
  ffmpeg -i captions.srt captions.vtt
  ```

- 验收看最终输出，不只看剪辑预览。检查开头人物动作、字幕安全区、用户点击、真实结果、品牌与入口。完整解码视频及存在的音轨，确认 16:9 或 9:16、预期时长、字幕模式和画面。检查静音观看能否理解剧情，开启声音后确认字幕和人声一致。区分演示验收、真实产品验收和发布验收。
- 用户明确要求上线时，按站点拥有方现有发布路径操作。官网可在原生播放器提供封面、按钮、可选字幕和 `preload="none"`。发布后在公网验证播放、跳转、字幕、移动布局与 MP4 字节范围响应。只部署本次授权的内容，已有工作区改动和线上行为应保留。
